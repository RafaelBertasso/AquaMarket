O **AquaMarket** é uma plataforma de marketplace desenvolvida utilizando a metodologia **Spec Driven Development (SDD)**.

---

## 📌 Visão Geral

O projeto tem como objetivo entregar uma solução moderna, robusta e escalável para comércio eletrônico, priorizando a clareza arquitetural e o alinhamento total entre especificações e implementação.

---

## 🛠️ Tecnologias Utilizadas

### Backend
- **C# / .NET 8.0** com **Clean Architecture**
- **Entity Framework Core**
- **PostgreSQL** via **Supabase**

### Frontend
- **React** + **Vite** + **TypeScript**
- Componentização modular e estilização moderna
