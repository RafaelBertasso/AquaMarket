# Glossário de Linguagem Ubíqua (DDD) - AquaMarket

Este documento estabelece o **Glossário da Linguagem Ubíqua** (Ubiquitous Language) do AquaMarket, conforme os princípios de Domain-Driven Design (DDD). O objetivo é garantir um vocabulário comum e sem ambiguidades compartilhado por desenvolvedores, especialistas de negócio e demais partes interessadas.

---

## Termos do Domínio

| Termo | Definição |
|---|---|
| **Vendedor** | Usuário que cadastra e vende produtos no marketplace |
| **Comprador** | Usuário que navega, busca e compra produtos |
| **Produto** | Item disponível para venda no marketplace |
| **Pedido** | Solicitação de compra feita por um comprador |
| **Categoria** | Classificação hierárquica dos produtos |
| **Avaliação** | Feedback dado por um comprador sobre um produto ou vendedor |
| **Carrinho** | Coleção temporária de produtos selecionados para compra |
| **Pagamento** | Transação financeira associada a um pedido |
| **Entrega** | Processo de envio do produto ao comprador |
| **Loja** | Perfil/vitrine do vendedor no marketplace |

---

> [!IMPORTANT]
> Este glossário é um documento vivo e **deve ser atualizado continuamente sempre que novos termos de domínio forem introduzidos** ou quando houver refinamentos na linguagem de negócio da aplicação.
