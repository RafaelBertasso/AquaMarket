# AquaMarket — Frontend

Documentação do módulo frontend do projeto **AquaMarket**.

## Stack Tecnológica

- **React**
- **Vite**
- **TypeScript**

## Status do Projeto

- **Status**: Aguardando scaffold via skill dedicada.
- O projeto será inicializado utilizando o Vite como bundler e ambiente de desenvolvimento.

As seguintes definições de arquitetura e bibliotecas serão refinadas em especificações futuras:
- Gerenciador de estado global (ex: Redux Toolkit, Zustand, Context API).
- Biblioteca de roteamento (ex: React Router).
- Biblioteca de componentes / UI kit (ex: Tailwind CSS, Shadcn UI, Material UI).
- Framework e ferramentas de testes (ex: Vitest, React Testing Library, Cypress/Playwright).
